# Filament Library V1 — As-Built Production Scope

This document records the current V1 acceptance boundary. It is intentionally limited to the implemented filament-library path; preset generation remains V1 beta and is not a launch gate.

V1 includes:

1. Public filament-library entry points in English and Simplified Chinese.
2. Published filament listing with brand and material context.
3. Product detail routes for published filament color records.
4. Brand/material navigation and filtering.
5. Color search and color/SKU presentation.
6. Technical parameter presentation from the canonical published projection.
7. Product and color image asset loading.
8. Stable URL routing for list and detail pages.
9. Empty and not-found states on the public catalog path.
10. Admin draft list and detail readback.
11. Admin review and publish controls for authorized administrators.
12. Published-state persistence and public visibility filtering.

Out of scope for the V1 launch gate:

- Bambu preset completeness and full printer matrix validation.
- OCR/FIP development or reprocessing.
- Historical duplicate cleanup outside an explicitly confirmed canonical binding.
- New brand-management, spool-color, or other catalog expansion work.
